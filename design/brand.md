# Open Typora 品牌标记

唯一矢量源是 [icon.svg](icon.svg)。两张展开的书页构成字母 T 的横画，带弧度的笔形竖画和底部衬线形成完整标记。墨蓝主体与一小段灰蓝页边置于纸白底座，不加入文档折角、文字缩写或小尺寸细节。

- 纸白 `#ffffff`、底座阴影色 `#edf1f5`。
- 墨蓝 `#35465e` / `#1d2a3e`、页边灰蓝 `#6d8cae`。
- 1024 方形画布，底座四周留 64 单位；标记居中，以实际 16/32/64/128 像素检查识别度。
- 应用图标和“关于”窗口共用这份源文件。`scripts/icon.mjs` 生成 PNG 与 ICNS，不再单独绘制一份标记。
