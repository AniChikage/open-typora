# 参考文件、目录问答与版本历史

[English](workspace.md) · 简体中文

这些功能用于桌面版的本地 Markdown 文件。AI 是可选功能，需要在「编辑 → 模型设置…」接入自己的兼容 API 或本地模型；应用不附带模型、云端订阅或免费额度。服务配置和密钥保存方式见 [AI 指南](ai.zh-CN.md)。

## 用参考文件改写选区

选中文字并打开 AI 改写，在要求中输入 `@文件名`，或点击「添加参考文件」，从已打开文档和当前授权文件夹中选择。已选文件以标签显示，可以移除；浏览列表不会请求模型。

点击「生成改写」后，应用在本机读取所选文件，选取相关片段，再将选区、改写要求和片段发送给当前模型。已打开文档使用当前未保存的文字；不会自动附带其他标签页。参考资料无法读取或超过限制时，会先停止发送，请移除或换用较小的文件。

生成的修改仍需逐项审阅，采纳作为一次可撤销编辑，并在本机记录修改前后的版本。等待快照时，如果切换文档、修改原文、进入组合输入或开启只读，旧操作不会覆盖当前内容。

## 询问文件夹里的内容

1. 打开 Markdown 文件夹，选择「编辑 → 目录问答…」，也可改为仅检索「已打开的文档」。
2. 使用文档中的关键词提问，点击「检索资料」。读取、切片和关键词排序都在本机完成；排序使用独立 Worker，这一步不请求模型。
3. 展开片段，检查原文和行号，取消勾选不想发送的资料。
4. 点击「发送所选片段并提问」，只把这些片段和问题交给当前模型。
5. 核对回答及引用。「打开原文」可跳转到文档，之后点「返回目录问答」继续查看原来的结果。原文改变时会提示行号可能已经移动。
6. 复制回答、另建草稿，或插入当前文档。插入会生成 Markdown 脚注，能建立相对文件链接时会附上链接，支持一次撤销。未保存的资料和 Windows 不同盘符的文件使用普通来源名称，避免生成错误路径。

模型必须返回已提供的来源编号和能在片段中找到的原文引用。不存在的编号、伪造引文、缺失引用和格式错误都会被拒绝；模型报告资料不足时不能直接插入。引用匹配只证明文字来自给定片段，不能证明推理正确，结论仍需自己检查。

目前采用关键词匹配，中文使用双字词片段；没有向量索引、联网搜索或自动代理。问题与原文用词差异较大时，换用更具体的关键词。应用不会执行资料中的指令，也不会自动批量修改文件。

### 检索范围与限制

| 项目 | 范围 |
| --- | --- |
| 单份参考文件 | 不超过 2 MiB |
| 改写显式参考 | 最多 4 份文件 |
| 目录检索 | 每次接纳最多 30 MiB 资料，分批读取时可能多读一批才发现预算已满 |
| 证据片段 | 最多 8 段，保留来源名称和原始行号 |
| 模型上下文 | 参考文字最多 48,000 个 UTF-16 单位；具体服务的 token 限制可能更小 |

无法读取的文件和预算限制会显示在界面中。检索不完整时，请缩小文件夹或只选择已打开文档。这些是参考检索限制，不限制大文档的打开、编辑和保存。读取沿用已有文件授权，拒绝被替换为符号链接的文件；作为参考读取不会自动打开文件或加入恢复会话。

请求包含文件名和片段，不额外附带宿主的绝对路径、授权 token 或文件摘要。但原文自身可能包含个人信息、路径和密钥，发送前应检查。资料和模型输出按文字处理，不作为命令执行；生成不会自动写入文档。

## 跨重启的版本历史

在「文件 → 版本历史…」查看本机快照。可以先保存当前快照，再尝试修改；选择旧版本可查看和恢复。恢复前也会记录当前内容，一次撤销即可回到恢复前。只查看不会修改文档。

打开、保存、未保存编辑停止八秒后、采纳 AI 修改及恢复版本时会记录快照。保留旧基线的前提下，30 秒内连续保存／自动快照会合并；最新内容相同则不重复记录。应用内另存为、重命名和移动会带走对应历史；应用外改名不会自动迁移历史。

快照单独保存在应用数据目录的 `versions-v1`，与恢复会话、内存中的撤销记录分开。每份文档最多保留 **50 个版本、128 MiB** 不重复正文，全部历史合计 **512 MiB**；超出预算时清理最旧版本。界面仅预览前 24,000 字符，恢复使用完整内容。超过快照预算的大文档仍可编辑和保存，但不能记录该大小的快照。

快照是明文 Markdown；平台支持时，文件权限为仅当前用户可读写。损坏内容校验失败后不会恢复，不可读取的索引保留并提示。历史保存失败不阻止文档正常保存。这是有限保留的恢复工具，不代替自己的备份。

## 中英文界面

在偏好设置的「语言 / Language」选择 English 或简体中文。设置保存在本机，切换时更新应用控件和菜单，保留编辑器、文档内容和撤销记录。已有配置仍默认中文；系统文件对话框使用系统语言，第三方插件和自定义主题名称可保留自身语言。
