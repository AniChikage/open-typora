# AI 选区编辑

[English](ai.md) · 简体中文

AI 编辑是桌面版的可选功能，需要自行配置模型服务。应用不附带模型、API 密钥或付费订阅，不配置也不影响 Markdown 编辑。网页试玩不接收模型密钥，也不请求模型服务。

## 连接模型

打开 **编辑 → 模型设置…**，或 **偏好设置 → AI 改写 → 模型设置…**。选择接口格式，填写服务地址、准确的模型名称，以及服务要求的 API 密钥。

| 服务 | 接口格式 | 地址示例 |
| --- | --- | --- |
| 自定义兼容 API | OpenAI 兼容 API / LM Studio | 服务商提供的基础地址，通常以 `/v1` 结尾 |
| OpenRouter | OpenAI 兼容 API / LM Studio | `https://openrouter.ai/api/v1` |
| LM Studio | OpenAI 兼容 API / LM Studio | `http://127.0.0.1:1234/v1` |
| Ollama | Ollama 原生接口 | `http://127.0.0.1:11434` |

点击 **保存并测试连接** 会先保存配置，再发送公开文本 `你好` 和固定的简短测试要求；不会读取当前文档作为测试内容。只想保存时，点击 **保存设置**。打开设置或文档不会自动请求模型。

兼容接口使用非流式 `POST /chat/completions`：填写根地址时补为 `/v1/chat/completions`，自定义路径前缀和完整接口地址按配置保留。Ollama 使用非流式 `POST /api/chat`。其他专有接口格式需要服务商提供兼容端点才能使用；本版没有工具调用、联网浏览或全文件夹代理。

LM Studio、Ollama 需要自行安装、启动服务并加载模型，应用不会安装或启动模型服务。填写服务内实际可用的模型名；是否需要密钥取决于本地服务配置。

OpenRouter 需要自己的密钥，模型名请从[当前目录](https://openrouter.ai/models)复制。模型可用性、价格和[请求限额](https://openrouter.ai/docs/api/reference/limits)由服务商决定。应用只发送配置中的模型 ID，不会自行改用其他模型。

## 改写与审阅

1. 在正文或源码中选中文字。粗体、列表、表格单元格和局部代码编辑器都使用 Markdown 源码选区书签。
2. 点击星光按钮，或按 **⌘⇧R**（macOS）／**Ctrl+Shift+R**（Windows/Linux）。也可以使用 **编辑 → AI 改写选区…**。
3. 填写改写要求，或选择“更简洁”“润色”“译为英文”，再点击 **生成改写**。
4. 逐项比较原文与建议，取消不想采用的修改，也可以全部保留原文。生成本身不会修改或保存文档。
5. 点击 **应用 … 处修改**，把勾选的结果作为一次独立事务写入选区。一次撤销恢复原文，重做恢复已采用的结果。侧栏保留改写要求并清空已应用的差异，点击 **继续改写** 可处理刚采纳的文字；也可以重新选择文字后点击 **读取当前选区**。每次采纳都有独立的撤销步骤；关闭面板只丢弃尚未应用的建议。

只发送选区、改写要求和固定的保留原意指令，不自动附带全文、文件路径、其他标签或相邻段落。因此，选区过小时模型可能缺少上下文。应用前请核对姓名、数字、事实、代码、链接与 Markdown 语法；提示模型保留信息不能保证输出正确。

生成期间可以继续编辑。文档文字或活动文档发生变化后，旧建议不能直接应用；需要回到未变化的原文和目标位置，或重新选区生成。切换分屏不会把建议写进另一侧。只读插件阻止 AI 写入；**取消生成**会终止等待，之后到达的旧结果被忽略。

捕获选区、应用结果和按键提交均受输入法组合状态保护。模型返回时不转移编辑焦点，输入法候选期间按 Esc 不会关闭设置对话框。请先完成选词，再开始或应用改写。

## 密钥与数据

- 从 0.20.2 起，macOS 将记住的密钥明文保存在 `~/Library/Application Support/Open Typora/ai-settings.json`，权限为 `0600`，仅当前用户可读写。正常打开设置、改写和重启后都读配置文件，不访问钥匙串。请勿提交或分享这份配置文件。Windows/Linux 仍使用 Electron 的系统加密存储，拒绝通过 Linux 的不安全 `basic_text` 后端持久保存。
- macOS 取消勾选 **保存密钥到本机配置文件**，Windows/Linux 取消勾选 **使用系统安全存储记住密钥**，密钥就只保留到应用退出，不写入磁盘。无鉴权的本地服务可以留空。
- 对 0.20.1 及更早版本的配置，应用先尝试不弹窗迁移自己的旧钥匙串条目。需要授权时，在模型设置点击 **迁移旧密钥到配置文件**，或重新填写一次。显式迁移可能需要最后一次系统授权；成功后不再查询钥匙串，旧条目也不再使用。不要把密钥发到聊天或 Issue 中。
- 设置只向界面返回密钥是否存在和存储方式，不回传已保存的密钥；保存后清空密码框。更换服务地址不会沿用旧地址的密钥。
- 地址不能包含账号密码、查询参数或片段。HTTP 重定向会被拒绝，避免通过重定向向另一端点转发密钥和选区。
- 选区会发送给你配置的服务。测试第三方服务时请使用公开样例。本地服务是否继续转发数据，取决于该服务自身配置。

文档、主题和恢复会话独立于模型配置。

## 资源限制与报错

单次选区上限为 **200,000 个 UTF-16 代码单元**，要求上限为 **8,000**；模型服务可能有更小的上下文或 token 限制。结果同样限制为 200,000 个代码单元，HTTP 响应上限为 2 MiB，超时为 180 秒。每个应用服务最多同时处理四个请求，不会自动反复重试。

空结果或被截断的结果不能应用。鉴权、地址、限流等失败不改动文档，也不会把服务商错误响应正文直接回显到编辑器。连接测试失败时，合法配置仍会保存，界面单独显示请求失败。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 测试连接失败 | 确认接口格式、地址、准确的模型 ID、密钥及服务商额度。测试失败不代表配置未保存。 |
| 连不上本地模型 | 单独启动 LM Studio 或 Ollama，加载模型，核对主机与端口。应用不会代为启动服务。 |
| macOS 提示旧密钥待迁移 | 在模型设置点击 **迁移旧密钥到配置文件**，或重新填写一次并保存。以后重启均读配置文件；不要在 Issue 中发送密钥或配置文件。 |
| 不能应用建议 | 完成候选输入、退出只读模式，并确认当前文档和目标位置仍为未变化的原文；文字已经变化时重新选区生成。 |
| 结果为空、截断或超限 | 缩小选区或改写范围，核对模型上下文和输出限制。被拒绝的结果没有修改文档。 |

报告问题时附上应用和系统版本、接口类型、不含秘密的报错，以及可公开的最小选区和要求。删除密钥、私有地址及不能分享的文档内容。

## 验收范围

`npm run test:ai` 使用实际 Electron 界面和自有 HTTP 服务，覆盖配置、发送范围、逐项审阅、Markdown 容器、局部代码与源码、保存字节、撤销重做、过期结果、取消、组合输入保护、只读插件和分屏。它不代表模型生成质量，也不等同于系统候选窗实测。

macOS 的 `npm run test:ai-native` 验证实际 URLSession 传输；`npm run test:ai-webkit` 验证原生桥和 WebKit 审阅流程。这些确定性夹具不需要第三方密钥。Windows/Linux 安装包会对实际发布程序执行 AI 界面验收。

[0.20.0 验收记录](verification.md)单独记录真实自定义 API 改写和 macOS 搜狗拼音人工检查，包括 AI 要求、正文、粗体、列表、表格、代码及撤销重做。Ollama 已完成协议测试，本轮未运行本地模型权重；其他模型服务、实体输入法和桌面环境组合未穷尽。
