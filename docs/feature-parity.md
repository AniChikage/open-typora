# Typora 功能对齐清单

当前交付版本：**0.9.0，macOS arm64 / Windows x64 / Linux x64**。基准为本机 Typora 1.14.10 的菜单、实际交互和官方公开文档。功能存在、自动化通过与完整等价是不同结论；未验证的组合不写成已对齐。

公开依据：[Markdown](https://support.typora.io/Markdown-Reference/)、[文件管理](https://support.typora.io/File-Management/)、[图片](https://support.typora.io/Images/)、[导出](https://support.typora.io/Export/)、[HTML](https://support.typora.io/HTML/)、[快捷键](https://support.typora.io/Shortcut-Keys/)。REA 的静态证据及覆盖边界见 [research.md](research.md)。

| 能力 | 当前状态 | 实现与证据边界 |
| --- | --- | --- |
| 原生窗口、正文 DOM、独立源码视图 | 已实现 | AppKit/WebKit 发布；源码独立历史、返回正文合并事务。内部模型为独立实现 |
| 行内语法、撤销、列表、代码/公式局部编辑 | 已实现并回归 | 源位置映射、组合输入时保留 DOM、跨模式历史；实体输入法全部组合仍未穷尽 |
| 段落、标题、引用、列表、任务与缩进 | 已实现并回归 | 共享命令定义驱动原生菜单/快捷键；多行列表与引用列表 Tab/Shift-Tab 保留选区、支持单次撤销；混合嵌套选区仍有待覆盖的组合 |
| 行内样式与清除格式 | 已实现并回归 | 跨叶格式及部分嵌套选区清除保留两侧样式；单次撤销还原 |
| 平台快捷键与代码缩进 | 已实现并回归 | Mac 保留现有映射；Windows/Linux 使用 Ctrl+P、Ctrl+T、Ctrl+Shift+K/M/Q、Ctrl+Shift+1/2/3 等公开绑定，菜单与插件快捷键预留共用映射；局部代码多行 Tab/Shift-Tab 不替换选区内容 |
| 选词、选行、格式范围与定位 | 已实现并回归 | Cmd/Ctrl+D 选词（包含中文分词）、Shift+D 删除词语并单次撤销；L 选行/表格行，E 扩展嵌套格式范围/选单元格，J 跳回选区；源码及局部代码共用选词/选行/定位，源码范围按语法树扩展；只读允许选择与定位 |
| 表格 | 已实现并回归 | 行列增删/移动/对齐、Tab 导航、TSV/HTML 网格粘贴、扩展尺寸、转义管道；Cmd/Ctrl+Enter 在当前位置下方插行，Shift+Enter 保留单元格内换行；Markdown 本身没有合并单元格语法 |
| 目录、脚注、YAML、引用链接 | 已实现并回归 | 重复标题 slug、目录跳转、脚注定义编辑、前言隐藏、引用链接定义插入；复杂嵌套脚注未穷尽 |
| 高亮、上下标、Emoji、注释、警告块 | 已实现并回归 | 可关闭扩展；Emoji 前缀建议支持方向键/Enter/Tab；NOTE/TIP/IMPORTANT/WARNING/CAUTION 预览 |
| HTML 与媒体 | 已实现，范围有限 | CommonMark HTML 块、局部源码编辑、静态 HTML、图片尺寸、音视频与沙盒 HTTPS iframe；会清理脚本/事件属性。第三方嵌入站点及全部 CSS 组合未验收 |
| 剪贴板 | 已实现并回归 | 自有 Markdown、纯文本和清理后的 HTML；表格网格粘贴；所有浏览器/办公软件剪贴板组合未穷尽 |
| 自动配对、拼写检查、字体/缩进 | 已实现并回归 | 正文、源码、局部代码块设置更新；新增组合输入期间的保存/关闭/磁盘刷新保护；本机搜狗人工中文输入已核对正文、单次撤销/重做、源码往返及 UTF-8 保存；修复空段落元素光标的组合提交丢字，新增单元及原生 WebKit 回归；其他输入法/编辑位置组合未穷尽 |
| 专注、打字机、字数与选区统计 | 已实现并回归 | 淡化其他块、caret 居中、字/词/字符/行数/预计阅读；逐行淡化、阅读速度可配置；官方全部统计口径仍待穷尽 |
| 文件列表/树、排序和快速打开 | 已实现并回归 | 空文件夹、自然/字母/修改/创建排序、倒序、文件夹优先、方向键、最近文件；目录前 1000 项、最多 8 层 |
| 新建、复制、重命名、移动、废纸篓与撤销 | 已实现并回归 | 当前草稿准备、所有窗口路径同步、恢复会话提交、拖到文件夹移动；文件内容撤销与文件操作撤销独立 |
| 最近项目、置顶文件夹与全文搜索 | 已实现并回归 | 本机持久化、清除/移除/置顶；大小写/正则搜索定位到文件行，显示前 500 匹配。超大/不可读取文件明确报告跳过 |
| 新窗口/标签页、恢复、关闭与重开 | 已实现并回归 | 原生标签组恢复、保存/取消/不保存、退出保留草稿；已关闭窗口的路径历史可跨重启；未命名文档历史仍有限 |
| 保存、自动保存、冲突与编码 | 已实现并回归 | 原子保存、提交前哈希、UTF-8/UTF-16 LE/BE/GB18030/GBK/Big5/Shift JIS/Windows-1252、BOM/LF/CRLF、无损检查、重开/转换保存、恢复和编码变化冲突；传统编码由用户显式选择 |
| 图片路径、复制与尺寸 | 已实现并回归 | 相对/绝对路径、本地 YAML 根目录、YAML 复制目录、文件名变量、转义与 ./ 偏好；右键编辑路径/alt/宽高 |
| 图片文件管理、下载与上传 | 已实现，外部服务有条件 | 移动/重命名/复制/废纸篓、批量移动/复制/下载、PicGo 上传/自动上传。未命名草稿可插图、正文与源码均支持多图队列；macOS 原生与 Windows/Linux Electron 均提供文件管理；Electron 批量复制失败回滚新文件，完成全部复制后才将原文件移到废纸篓。接口经自有本机 HTTP 服务验证；实际图床需要用户配置并完成真实上传验收 |
| 内部及跨文件链接 | 已实现并回归 | 当前标题/脚注、已打开文件夹内相对/绝对 Markdown 路径、目标窗口就绪后标题跳转、缺失文件创建；目录外文件需先显式打开 |
| 正文查找与替换 | 已实现并回归 | 正文与源码均支持大小写、全词、正则；捕获组替换、零宽匹配和单事务全部替换 |
| MathJax、Mermaid | 已实现并回归 | 离线公式、宏、字体与 SVG；新增 sequence/flow 常用语法预览和导出，保留原文，未支持的语法明确报错；使用 Mermaid 布局，非 js-sequence/flowchart.js 外观等价；[范围](diagrams.md) |
| HTML 与 PDF 导出 | 已实现并回归 | HTML 内嵌字体/图片/自定义主题；PDF 按文本行/标题/表格行分页、逐页向量生成、A4/Letter、边距及页眉页脚变量；13 页样本逐页检查，段落/行无丢失重复；另检查两页中文复杂样本的公式、图片、图表、表格和脚注。文本检查采用 Unicode 兼容规范化 |
| Word/RTF/ODT 与 Pandoc | 已实现，有依赖边界 | 本机 Pandoc 3.12.1 实际生成 10 种格式，DOCX/ODT/RTF/EPUB 中文复杂样本重新导入；DOCX 原生公式、表格、脚注、图片结构已检查。导出嵌入图表与图片；文本格式保留同名资源目录。RTF 额外保留表格/脚注/PNG/JPEG/标题/代码；WMF/EMF、脚注内图片拒绝而非静默丢失。Windows/Linux 增加 LibreOffice + Pandoc 的 DOC/RTF 导入，以及 DOCX/ODT/EPUB 持久媒体提取；实际转换、渲染、HTML 导出与重启后媒体读取随安装包验收；修正新版 Pandoc 默认公式语法。其他任意格式组合未穷尽 |
| 内置主题与 CSS 安装 | 已实现并回归 | 六套原创主题；macOS/Windows 均内嵌本地 CSS 导入、字体、图片，适配常用选择器和颜色变量；第三方主题仍是部分兼容 |
| 可视化背景图片 | 已实现，已验收本机 WebKit | PNG/JPEG/WebP 本地选择及副本保存，不透明度、模糊、填满/完整/平铺、五种位置、重置和清除；正文/源码模式共用，个人背景不带入导出。限制 8 MB / 4000 万像素；Windows 安装后验收随发布运行 |
| 第三方插件兼容 | 部分兼容，已有实际运行 | 五款固定版本 obgnail/typora_plugin 原版源码、单文件 CommonJS 安装、配置、生命周期、快捷键、禁用清理和卸载；原生 WebKit 已验收安装模块动态导入、可撤销文档修改及只读保护。未兼容完整插件包、Node/Electron、外部模块及所有 Typora 私有接口；详见 [plugins.md](plugins.md) |
| 安装更新与旧版本清理 | 已实现并回归 | M 图标保留；验证新包后替换安装版并删除临时回滚包；只保留当前版本归档。用户文档/草稿不属于版本清理对象 |
| Windows、其他平台与签名 | 部分交付 | Windows x64 提供 NSIS EXE / ZIP，由 Windows runner 安装后验证编辑、保存、PDF、图片、恢复、单实例与文件关联；Windows 10/11 实体候选交互尚未人工验收。Linux x64 新增 DEB / AppImage，Ubuntu 22.04 runner 验证 DEB 安装/卸载与恢复数据保留、两个包内应用的编辑、PDF、插件、背景和第二实例打开文件；AppImage 使用解包运行验收，FUSE 挂载及不同桌面环境未人工验收。Windows/Linux ARM / Intel Mac 未交付；Windows 无代码签名证书，macOS 未公证 |

剩余项为其他输入法及列表/表格/局部代码的完整候选组合、未覆盖的跨应用剪贴板/复杂跨块编辑、第三方主题与图形扩展，以及 Windows 实体输入法，Intel Mac / ARM 等其他平台发布。复杂转换覆盖已列样本和目标格式，无法代表任意格式无损往返。**0.9.0 仍不能标为 Typora 全功能完全等价**；外部图床真实上传仍需独立配置与验收。
