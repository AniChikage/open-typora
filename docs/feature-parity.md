# Typora 功能对齐清单

目标是独立实现 Typora 的写作能力。此清单以本机 macOS Typora 1.14.10、2026-10-14 的官方菜单及公开文档为基准。**已有实现和测试通过不代表全部边界行为与官方一致。**

公开依据：[Markdown 语法](https://support.typora.io/Markdown-Reference/)、[快捷键](https://support.typora.io/Shortcut-Keys/)、[文件管理](https://support.typora.io/File-Management/)、[专注与打字机模式](https://support.typora.io/Focus-and-Typewriter-Mode/)、[字数统计](https://support.typora.io/Word-Count/)。REA 静态证据的范围和 unknown 见 [research.md](research.md)。

| 能力 | 0.3.0 状态 | 已覆盖的行为 / 剩余差异 |
| --- | --- | --- |
| 原生宿主、DOM 正文、独立源码视图 | 已实现，自动化和真窗口验证 | AppKit/WebKit；源码历史隔离、返回正文提交事务。内部节点和历史实现仍是独立实现 |
| 光标进入行内语法、撤销、列表输入、代码/公式局部编辑 | 已实现，内核与桌面回归 | 结构操作保留源位置。实体中文输入法和全部复杂选区仍待对照 |
| 标题 1–6、段落、引用、有序/无序/任务列表、缩进 | 已实现，内核和快捷键回归 | 同一命令定义驱动原生菜单及键盘；嵌套和极端混合选区仍有边界 |
| 粗体、斜体、删除线、下划线、行内代码、清除样式 | 已实现，内核回归 | 跨叶格式分别应用，保留块结构；复杂部分选区的清除样式仍不完整 |
| 表格 | 已实现，内核及对话框回归 | 单元格编辑/导航、行列增删/移动、对齐、源码格式化；复杂粘贴、合并单元格与全部官方工具未对齐 |
| 正文目录、脚注、YAML 前言 | 已实现，内核与桌面回归 | 标题重复 slug、目录跳转、脚注编号/定义编辑、前言不导出；脚注复杂嵌套仍需扩展 |
| 高亮、上下标、Emoji、注释、受限行内 HTML | 已实现，内核回归 | 可关闭语法扩展；尚无 Emoji 自动补全和完整 HTML/媒体 |
| HTML / Markdown / 纯文本剪贴板 | 已实现，内核回归 | 自有 Markdown 类型、格式平衡、HTML 清理与转换；全部浏览器/办公软件粘贴尚未验收 |
| 自动配对、拼写检查、字体/缩进偏好 | 已实现，桌面回归 | 正文、源码和代码块配置更新；复杂候选输入与特殊字符组合待验证 |
| 专注与打字机模式 | 已实现，桌面几何回归 | 淡化其他块、保持 caret 在编辑区中部；逐行聚焦和长代码块细节仍有差异 |
| 字数、字符、行数、阅读时间和选区统计 | 已实现，单元检查 | 汉字逐字计数，字数剔除语法；阅读速度配置和官方全部统计口径待对照 |
| 大纲、文件列表/树、快速打开 | 已实现，桌面回归 | 已打开文档及已授权文件夹的 Markdown 文件；文件树方向键、排序和全局内容搜索尚未补齐 |
| 新窗口/标签页、恢复、重新打开关闭文件 | 已实现，文件层与真窗口验证 | 原生标签组恢复、重新读取磁盘、关闭前保存/取消/不保存；关闭历史跨重启和全部窗口语义未对齐 |
| 保存、自动保存、冲突、编码 | 已实现，真实文件系统回归 | 原子保存、BOM/LF/CRLF、脏草稿恢复；其他编码和官方所有恢复策略未对齐 |
| 图片 | 部分实现 | 本地插入/粘贴/拖入、文档目录内相对资源；图片缩放、上传、远程读取、根目录规则和清理待实现 |
| 内部链接 | 部分实现 | 当前文档标题/脚注跳转、目录内相对 Markdown 文件打开；跨文件锚点和目录外路径未接入 |
| MathJax、Mermaid | 已实现，WebKit/桌面渲染回归 | 离线公式、宏、字体和 SVG；全部 Typora 扩展与复杂图形仍待对照 |
| HTML / PDF 导出 | 部分实现 | 独立 HTML 嵌入字体/本地图片，异步向量 PDF；长文分页、页眉页脚、打印设置仍待完善 |
| 警告块、引用链接工具、完整 HTML/媒体 | 待实现 | 尚未提供完整的官方交互和渲染 |
| 文件重命名/移动/删除、最近文件、全局搜索 | 待实现 | 需与文件授权、未保存草稿和恢复策略一起实现 |
| Word、Pandoc 导入导出、主题安装 | 待实现 | 当前只提供内置主题与 Markdown 文件读写 |
| Windows/Linux 发布、签名公证 | 待实现 | Electron 仅作开发与回归宿主，发布目标是 macOS arm64 |

后续优先补齐文件管理与链接、复杂选区/输入法、图片与搜索、长文导出，再扩展高级语法和导入导出。每项功能需要同时通过源文本/历史测试和实际交互回放；只增加菜单入口不算完成。
