# Typora 功能对齐清单

当前交付版本：**0.17.3，macOS arm64 / Windows x64 / Linux x64**。基准为本机 Typora 1.14.10 的菜单、实际交互和官方公开文档。功能存在、自动化通过与完整等价是不同结论；未验证的组合不写成已对齐。

公开依据：[Markdown](https://support.typora.io/Markdown-Reference/)、[文件管理](https://support.typora.io/File-Management/)、[图片](https://support.typora.io/Images/)、[导出](https://support.typora.io/Export/)、[HTML](https://support.typora.io/HTML/)、[快捷键](https://support.typora.io/Shortcut-Keys/)。REA 的静态证据及覆盖边界见 [research.md](research.md)。

剩余项为其他输入法及列表/表格/局部代码的完整候选组合、未覆盖的跨应用剪贴板/复杂跨块编辑、第三方主题与图形扩展，以及 Windows 实体输入法，Intel Mac / ARM 等其他平台发布。复杂转换覆盖已列样本和目标格式，无法代表任意格式无损往返。**0.17.3 仍不能标为 Typora 全功能完全等价**；外部图床真实上传仍需独立配置与验收。

0.13.4 修复：缩进命令覆盖完整源码和局部代码编辑器，保留列表行为与独立撤销；Linux DEB 使用无空格安装路径，并增加前一公开 DEB 升级、GIO 与 KDE MIME 关联启动回归用例。初始 CI 验收环境为 Ubuntu 22.04 与 KDE 启动组件；之后 0.13.4 DEB 已在完整 Kubuntu 26.04 / Plasma 6.6.4 / Wayland 中完成 Dolphin 打开及 18 项键盘回归，见[版本化验收记录](verification.md)。这轮完整桌面检查尚未对 0.17.2 重跑，AppImage/FUSE 仍不在该验收范围内。

0.14.3 重点补充大文件源码性能、主题实时定制、可控打印分页和 Windows 系统预览。大文件保持源码模式；系统预览为只读且有 1 MiB 上限，不加载插件。FUSE 实际挂载仍未验收；完整 Kubuntu 26.04 桌面记录对应 0.13.4 DEB，不作为 0.14.3 的桌面验收结果。

0.15.0 继续补充大文件所见即所得编辑：可视块挂载、局部增量解析、保留代码块标识和中文组合提交，5/10 MiB 样本验证编辑与精确保存。Everything 取消 1 MiB 截断，改用文件／Shell Item 初始化保留图片目录，验证全文末尾及中文、空格、父目录相对图片。系统预览仍只读且不运行插件。

0.16.2 取消 Markdown 打开／保存／恢复的固定 20 MiB 上限，原生与 Electron 存储验证 32 MiB 草稿恢复、超过 64 MiB 的 UTF-16 编码输出。大代码块使用紧凑位置映射和局部 CodeMirror 视口；大表格采用行虚拟化与源位置导航。大型代码省略语法高亮和软换行；规则顶层管道表格可跳过屏外单元格解析。嵌套／不规则结构仍可能需要完整解析，尺寸不代表任意内存或插件组合的性能保证。

0.16.4 继续优化大型块：普通换行与反引号编辑只核对受影响代码行；若删字使一行变为闭合围栏，则正确重新识别块边界。规则表格按编辑范围更新行索引并保留未改行的 DOM；中部插行、中文／emoji 退格及撤销增加精确源码回归。位置映射合并偏移，缓存单元格不持有旧大文档；字素删除直接查当前位置，避免全文字素数组。

0.16.4 追加修复：快速左右移动后退格会同步结束上一编辑组，避免浏览器合并 selectionchange 后撤销丢失刚删除的 emoji；局部代码的选区变化也结束编辑组。Windows 安装验收保留原来的即时按键序列与精确文件断言。0.16.3 候选因该回归未发布。


0.17.2 增加原生能力桥接的右键交互：标签页提供关闭左右／其他／已保存／全部、保存全部、保存并关闭全部、文件名与路径复制、定位／打开文件夹、重命名、分屏和大纲。批量关闭先完成全部决策再移除标签；取消或保存失败保留整组标签，未命名草稿不归入“已保存”。正文／源码右键提供剪贴板、撤销重做、选择、格式／段落／插入入口；表格右键按点击位置增删、移动和对齐行列，支持虚拟化大表格。菜单保留选区、支持 Shift+F10、方向键／Esc、视口边界避让，遵守只读和组合输入保护。自动化验收覆盖原生 WebKit/AppKit 和 Chromium，以及 Windows/Linux 安装载荷；跨应用剪贴板的全部格式与实体输入法组合仍未穷尽。需求来源：[Issue #3](https://github.com/AniChikage/open-typora/issues/3)。

0.17.3 实测六款原版社区插件的样式、交互、跨标签/分屏、组合启用、重启及停用清理，修复折叠三角颜色缺省及 eWrite 监听仍绑定旧编辑器。macOS 系统中文候选验收覆盖正文/粗体保存，以及列表、表格、局部代码和源码的候选提交、单步撤销重做、取消候选及模式往返；不据此宣称其他输入法通过。真实 FUSE 和解包载荷分别记录，Ubuntu 24.04 的应用级权限前提不视作默认环境已经配置。
